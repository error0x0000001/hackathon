# EduTrack

EduTrack is a comprehensive educational management application designed to streamline various aspects of educational institutions, including class management, student enrollment, exam scheduling, and more. Built with Next.js, Prisma, and Tailwind CSS, EduTrack provides a responsive and user-friendly interface.

## Features

- Manage classes, students, teachers, and subjects.
- Schedule and manage exams.
- User authentication with Clerk.
- Calendar view for easy scheduling.
- Responsive design using Tailwind CSS.

## Technologies Used

- **Frontend:** 
  - Next.js
  - React
  - Tailwind CSS
  - React Hook Form
  - React Toastify

- **Backend:**
  - Prisma (ORM)
  - PostgreSQL (Database)
  
- **Other Libraries:**
  - Clerk for authentication
  - Moment.js for date handling
  - Recharts for data visualization
  - Zod for schema validation
